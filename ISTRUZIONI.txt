DEEPSEARCH PERSONALE v0.9.0 — altre sorgenti torrent (17 novembre 2026)
=================================================================

Questo pacchetto aggiorna il TUO addon custom, senza installare altri addon
su Nuvio e senza modificare TorBox, i filtri o gli altri profili AiOStreams.

CONTENUTO
- index.mjs: codice completo dell'addon, nuova versione 0.9.0
- wrangler.toml: configurazione con nuovi provider abilitati
- new-indexers.test.mjs: regressioni della versione precedente
- additional-sources.test.mjs: test delle nuove sorgenti e autenticazione

PROVIDER AGGIUNTI
A) BitTorrented (JSON public search; nessuna chiave)
B) The RarBg Search (JSON public text search; nessuna chiave)
C) TorBox Search (indice Orion/aggregati; richiede API key TorBox e piano abilitato)
D) TSP Multi-Indexer (aggregatore di indici; richiede una chiave generata dal sito tspsearch.dev)

I provider del v0.8 rimangono. TorBox Search e TSP restano inattivi finche'
non sono configurati i rispettivi Secret in Cloudflare.

INSTALLAZIONE
1. Nel repository GitHub annalisazotti11/Torrentaddon sostituisci i file
   index.mjs e wrangler.toml, mantenendo esattamente questi nomi.
2. NON cancellarli prima di sostituirli: evita build falliti.
3. Esegui il commit. In Cloudflare verifica che il nuovo build sia Ready e
   il nuovo deployment sia attivo al 100%.
4. L'endpoint privato /health deve rispondere con version 0.9.0.
5. NON cambiare ADDON_TOKEN. Non occorre reinstallare DeepSearch se manifest
   e token rimangono invariati.

CONFIGURAZIONE FACOLTATIVA (serve per far funzionare davvero i due aggregatori)
Cloudflare -> Worker torrentaddon -> Settings -> Variables and Secrets:
- TORBOX_SEARCH_API_KEY (Secret): tua API key TorBox da torbox.app/settings;
  la disponibilita' della Search API dipende dal piano TorBox.
- TSP_API_KEY (Secret): chiave da tspsearch.dev, servizio esterno.
Non mettere mai le chiavi in index.mjs, wrangler.toml pubblico o messaggi.
Se non imposti i Secret, l'addon usa comunque i nuovi BitTorrented e RarBg Search.

DIAGNOSTICA
Prova /debug/series/<IMDb_ID>:<STAGIONE>:<EPISODIO>.json dopo il
TUO_TOKEN, per verificare: received, accepted, error per sorgente.
Il JSON include optionalTorrentSources.torBoxSearchConfigured e
optionalTorrentSources.tspSearchConfigured, solo come true/false.

LIMITI
I test sono simulazioni locali con risposte controllate. Non e' stato
possibile interrogare i servizi reali da Cloudflare. Se un provider risponde
403/429/401/404 o cambia schema, potra' restituire zero risultati; il
resto dell'addon continua a funzionare. Nessun torrent specifico e' garantito.
Per contenuti disponibili sui servizi ufficiali resta attiva la sezione
RaiPlay / Mediaset Infinity / altri link gratuiti. Non ci sono bypass DRM.
